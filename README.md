# AJAZZ AJ139 V2 MC - Русская локализация софта (Russian Localization)

Неофициальный перевод программного обеспечения для игровой мыши **AJAZZ AJ139 V2 MC** на русский язык. 

Так как оригинальный софт не поддерживает добавление новых языковых файлов, русификатор работает путем замены стандартного китайского языка (файл `2052.lan`). Перевод выполнен на основе английской локализации с адаптацией всех технических терминов (LOD, Motion Sync, Debounce time и т.д.).

## Установка

Следуйте этой простой инструкции, чтобы установить русский язык:
## Вариант 1
1. Скачайте файл `aj139-russian.exe` из Releases.
2. Откройте его от имени администратора
3. Готово наслаждайтесь переводом!)
## ВАЖНО! В программе есть одноразовая телеметрия, то есть при запуске программы один раз отправляется уведомление для статистики, но после установки никакой телеметрии не будет! Если вы хотите избежать этой телеметрии, то советую воспользоваться вторым вариантом, или же, если наберётся достаточно просьб, сделаю версию без телеметрии. По поводу этого писать в TG @neobizshen. 

## Вариант 2
1. Скачайте файл `2052.lan` из этого репозитория.
2. Полностью закройте программу AJAZZ (убедитесь, что она закрыта в системном трее рядом с часами).
3. Перейдите в папку с установленной программой по следующему пути:
   ```text
   C:\Program Files (x86)\AJ139 V2 MC Gaming Mouse 1.2\language
   ```
4. *(Рекомендуется)* Сделайте резервную копию оригинального файла `2052.lan`, переименовав его, например, в `2052_backup.lan`.
5. Переместите скачанный файл `2052.lan` в эту папку с заменой старого файла.
6. Запустите софт для мыши.
7. Перейдите в настройки программы (иконка шестеренки) и в списке выбора языка выберите **Китайский** (Simplified Chinese / 简体中文).

Готово! Теперь весь интерфейс программы должен отображаться на русском языке.
